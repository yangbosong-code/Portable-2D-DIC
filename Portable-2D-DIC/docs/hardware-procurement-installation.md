# Portable 2D-DIC 全部硬件采购与安装方案

版本：2026-08-09。用途：学校科研、竞赛展示、室内单目平面 2D-DIC。计算盒预算按
2000～3000 元、最高 4000 元控制；相机、镜头、照明、标定和机械件另计。

> 采购红线：镜头、灯具长度、支架高度和标定板尺寸必须在视场 FOV 与工作距离 WD 确定后
> 下单。GalaxySDK ARM64 与目标 JetPack 未确认前，不采购无法退换的定制载板或批量设备。

## 1. 最终系统组成

```text
试样 + 散斑 + 标定板
        ↑ 均匀恒流 LED
ME2P-1840-21U3M + 高分辨率 C-mount 镜头
        │ 短距离锁紧 USB3
Jetson Orin Nano Super + NVMe + 主动散热
        │ 千兆网（主）/ Wi-Fi（辅助）
Windows 笔记本：DIC Studio 远程控制与显示
        └─ 可选：隔离触发盒 / DAQ / 试验机载荷
```

## 2. 采购状态说明

- **A：现在可以买**：不依赖 FOV，兼容风险低；
- **B：参数确认后买**：必须先确认视场、工作距离、试样尺寸或接口；
- **C：后续扩展**：第一阶段保留接口，不立即采购。

## 5. 镜头选型（B 类，不能盲买）

### 5.1 硬指标

- C-mount，覆盖 **1 inch/1.1 inch** 或更大靶面；
- 设计分辨率至少 18～20 MP，支持约 2.5 µm 像元；
- 手动光圈和手动对焦，均可锁紧；
- 低畸变，优先标称 TV distortion ≤0.1%；
- 工作距离覆盖实际布置，边缘 MTF 和照度不能明显塌陷；
- 不接受只覆盖 2/3 inch 的镜头；不只看“多少百万像素”，必须同时看靶面和像元规格。

### 5.2 焦距预选

传感器有效宽约 `4504×2.5 µm = 11.26 mm`。近似焦距：

`f ≈ WD × 11.26 / (FOV宽 + 11.26)`

| 目标水平 FOV | 建议 WD | 计算焦距 | 先测试的标准焦段 | 空间分辨率 |
|---:|---:|---:|---:|---:|
| 100 mm | 400 mm | 40.5 mm | 35/50 mm | 0.0222 mm/px |
| 200 mm | 500 mm | 26.6 mm | 25/28 mm | 0.0444 mm/px |
| 300 mm | 600 mm | 21.7 mm | 20/25 mm | 0.0666 mm/px |

表格只用于询价和借镜头测试，最终以厂家光学计算和实拍标定为准。若试样出平面运动明显、
边缘尺度一致性要求高，可询价大靶面远心镜头，但它通常体积大且价格显著超过普通镜头。

### 5.3 光圈起点

2.5 µm 像元对衍射敏感。建议从 f/4～f/5.6 开始，在景深与锐度间实测；不要为了景深直接
锁到 f/11～f/16。关闭自动曝光、自动增益和自动对焦，曝光先从 500～2000 µs、增益 0 dB
开始调整。

## 6. 照明与环境控制（B 类）

| 部件 | 数量 | 推荐规格 | 预算参考 |
|---|---:|---|---:|
| 高显色无频闪 LED 条形灯 | 2 | 24V 恒流、亮度可调、长度覆盖 FOV，左右 30°～45° 对称布置 | 600～2000 |
| 双通道恒流控制器 | 1 | 手动锁定亮度；无 PWM 条纹或频率远高于曝光带宽 | 300～1200 |
| 柔光板 | 2 | 消除热点，耐热，不直接接触灯珠 | 100～400 |
| 灯架/万向臂 | 2 | 锁紧后不漂移，不与相机架共振 | 200～800 |
| 交叉偏振片 | 1 套 | 金属、塑料高光试样可选；灯端+镜头端 | 150～800 |
| 遮光罩/黑布 | 1 套 | 屏蔽窗光、投影和竞赛现场闪烁照明 | 100～500 |

默认用两侧条形灯，不优先用单个环形灯；目标是全 FOV 灰度均匀且无饱和。若环境光无法控制，
再考虑单色绿光 LED 与匹配窄带滤光片，并重新确认镜头色差和相机响应。

## 7. 机械安装（B 类）

| 部件 | 数量 | 要求 | 预算参考 |
|---|---:|---|---:|
| 光学面包板或刚性铝型材底座 | 1 | 相机、灯具和试样夹具形成刚性闭环 | 500～2500 |
| 相机立柱/重型复制架 | 1 | 高度覆盖 WD，带粗调和微调，锁紧无回弹 | 500～2500 |
| 二维微调云台 | 1 | 小角度俯仰/偏航；锁紧后不移动 | 200～1000 |
| 试样夹具/小型加载架 | 1 | 由机械组按试样设计，不把载荷传到相机架 | 另计 |
| 防振脚垫 | 4 | 桌面振动明显时使用 | 100～500 |
| 安全绳与线缆夹 | 若干 | 防跌落、防插头受力 | 50～200 |

正式 2D-DIC 要让相机光轴尽量垂直试样平面，试样的出平面运动必须远小于工作距离。相机架和
试验机若放在不同的柔性桌面，会产生伪位移；优先固定到同一刚性基准。

## 8. 标定、散斑与质量检查（B 类）

| 部件 | 数量 | 要求 | 预算参考 |
|---|---:|---|---:|
| 平面点阵/棋盘标定板 | 1 大 1 小 | 覆盖实际 FOV 的 60%～90%；玻璃/铝基优先；有节距证书更好 | 300～5000+ |
| 钢直尺/量块 | 1 套 | 两点尺度快速检查，不代替畸变标定 | 100～800 |
| 哑光白底漆 | 1 | 与试样材料和应变范围兼容 | 50～300 |
| 哑光黑漆/喷笔 | 1 套 | 喷笔约 0.2 mm 喷嘴起步；可调散斑 | 200～800 |
| 散斑模板 | 若干 | 适合重复样件；目标散斑直径约 3～5 px | 50～300 |
| 刚体平移/微分头平台 | 1 | 验证已知亚像素/像素位移，可借用实验室设备 | 500～3000 |

物理散斑尺寸约为 `3～5 × FOV宽/4504`。例如水平 FOV 200 mm 时，目标直径约
0.13～0.22 mm。每个 21×21 px 子区内应含多个明暗特征，不能只有一个大斑点。

## 9. 网络、供电和安全（A/B 类）

- **主链路**：Jetson 与笔记本千兆网直连，建议静态地址 `192.168.10.2/24` 与
  `192.168.10.1/24`；DIC Studio 只传控制、降采样预览和结果，不传全速原始图；
- **辅助链路**：Wi-Fi 仅用于移动控制和展示；严禁用无线链路决定 Edge 是否继续记录；
- **供电**：原型阶段保留 Jetson 原装电源。相机由 Jetson USB 供电前先做满载稳定测试；
- **移动供电**：只有完成峰值功率、19V 稳压、接地、EMI 和续航测试后才加入电池/UPS；
- **接地**：试验机、照明、计算盒和相机出现地环路时，先查供电与屏蔽，不随意剪保护地；
- **运输**：运输前拆下长镜头或加镜头支撑，所有连接器加保护帽。

## 10. 触发与 DAQ（C 类，暂缓采购）

第一阶段只实现模拟载荷和接口，不建议现在购买 DAQ。后续确定以下信息后再选：载荷/应变/位移
通道数、信号范围、是否需要桥路、采样率、同步误差、隔离要求和试验机现有输出。

预留清单：

- 16 bit 或更高 USB/以太网 DAQ；
- 隔离数字触发输入/输出盒；
- 相机 GPIO 对接线；
- BNC/端子转换和屏蔽线；
- 试验机载荷模拟量或数字协议接口。

相机光耦/GPIO 电压必须以相机手册为准。Jetson 40-pin GPIO 不得直接连接未知电平、试验机
或长线，必须经过光耦/数字隔离和电平转换。

## 11. 到货与装配顺序

### 第 0 步：下单前确认

1. 向大恒提交相机完整型号、Jetson Orin Nano Super、ARM64、目标 JetPack/Ubuntu、
   4504×4096 Mono8 10/15/21.4 fps 和外触发需求；
2. 取得可用 Galaxy Linux ARM SDK、依赖列表和示例程序；
3. 测量试样最大尺寸，确定水平/垂直 FOV、WD、允许安装空间和最大出平面位移；
4. 把 FOV、WD、1/1.1 inch、20MP、2.5 µm、低畸变要求发给镜头供应商做书面匹配。

### 第 1 步：计算盒机械装配

1. 断电、佩戴防静电腕带；
2. 安装 M.2 2280 NVMe 和低矮散热片，确认螺柱位置正确；
3. 检查风扇线与叶片，不改动原装散热接触；
4. 装入通风机箱，先不接相机；
5. 接显示器、键鼠、网线和原装电源，首次开机检查风扇和 NVMe 枚举。

### 第 2 步：相机、镜头和照明装配

1. 在无尘环境装镜头，先锁定机身，再接 USB；
2. 长镜头增加支撑环，USB 线在相机后 5～10 cm 做应力释放；
3. 相机光轴垂直试样，试样占画面约 70%～85%，四周保留标定和漂移检查区域；
4. 两盏条形灯对称布置，先低亮度，再调光圈/曝光，最后增加亮度；
5. 锁紧焦距、光圈、云台、灯架和线缆；在锁紧后重新拍标定图。

## 12. Jetson 系统安装

### 12.1 版本选择

不要直接把 Windows 开发机的 CUDA 13.3 安装到 Jetson。Jetson CUDA 必须随匹配 JetPack
安装。优先级为：

1. 大恒确认可运行的 JetPack/Ubuntu；
2. NVIDIA 明确支持 Orin Nano Super 的正式 JetPack；
3. 本项目 CMake/CUDA 实机编译通过；
4. 再考虑是否升级更新版本。

优先使用 NVIDIA 官方安装介质或 SDK Manager。若需 Recovery 刷机，建议使用原生/双启动
Ubuntu x86 主机；虚拟机 USB 透传可用于尝试，但不作为唯一恢复方案。

### 12.2 基础系统

1. 安装选定 JetPack，完成固件更新；
2. 系统优先放在 NVMe；若单独数据分区，使用 ext4、UUID 挂载和 `noatime`；
3. 创建管理员账户，设置时区和 NTP；
4. 安装 `git cmake ninja-build build-essential pkg-config`；
5. 用 `nvidia-smi`（若该版本提供）、`nvcc --version`、`tegrastats` 检查 GPU/温度；
6. 用 `smartctl` 检查 NVMe；用 `fio` 做短时连续写入测试；
7. 用 `ip link`、`ethtool` 和 `iperf3` 检查千兆网。

### 12.3 GalaxySDK ARM64

大恒 2026-08-09 下载页公开的 Galaxy Linux Arm SDK 为 **V2.4.2507**，列出 GigE、2.5GigE
和 USB3.0；Windows SDK 为 V2.6.2607.9201。安装时严格按该 SDK 自带 README：

1. 安装运行库和 Development 头文件；
2. 执行厂家 USB 权限/udev 安装步骤；
3. 重启或重新加载规则；
4. 先运行厂家枚举/取流示例，再运行本项目；
5. 检查相机在 Mono8、全幅、10 fps 下连续取流，再升 15 和 21.4 fps。

## 13. DIC Edge 构建与安装

把项目复制到 Jetson 后：

```bash
export GALAXY_SDK_ROOT=/实际路径/GalaxySDK/Development
./tools/build-jetson.sh
sudo ./deploy/jetson/install.sh
```

安装器会：

- 创建独立 `p2dic` 服务用户；
- 安装程序到 `/opt/p2dic/bin`；
- 配置保存到 `/etc/p2dic/dic-edge.conf`；
- 数据写入 `/var/lib/p2dic/sessions`；
- 安装 systemd 自启动、健康检查和故障恢复；
- 用 `ldd` 拦截缺失的 CUDA/GalaxySDK 动态库。

检查：

```bash
systemctl status p2dic-edge.service
journalctl -u p2dic-edge.service -f
/opt/p2dic/bin/dic_ctl PING 127.0.0.1 17840
/opt/p2dic/bin/dic_ctl STATUS 127.0.0.1 17840
```

Windows DIC Studio 连接 Jetson 地址和端口 `17840/17841/17842`。防火墙只对实验室网段开放
这些端口，不把 Edge 直接暴露到公共互联网。

## 14. 分级验收

| 阶段 | 时长 | 通过条件 |
|---|---:|---|
| 计算盒空载 | 30 min | 无异常重启、NVMe/风扇/网络正常 |
| 合成 DIC | 30 min | CUDA 后端、结果流、预览流、保存与恢复正常 |
| 相机 10 fps | 30 min | 满幅 Mono8，无 USB 降速、无持续积压 |
| 相机 15 fps | 30 min | P95 延迟稳定，不随时间累积 |
| 相机 21.4 fps | 30 min | 记录真实 dropped/温度；达不到可降为性能上限而非隐瞒 |
| 静止试样 | 10 min | 位移/应变噪声、温漂和坏点比例有报告 |
| 刚体平移 | 多组 | 位移误差、重复性和空间一致性可量化 |
| 8 h 稳定性 | 8 h | 无泄漏、无磁盘满、无过热降频失控、结果可恢复 |
| 故障注入 | 每项一次 | 断网继续测量；相机断开、磁盘不足和进程崩溃有明确告警/恢复 |

## 15. 建议采购顺序

1. **第一批现在买**：Jetson 官方套件、2TB NVMe、散热片、机箱、网线、U 盘；
2. **第二批确认 FOV 后买**：镜头、相机支架、灯具、标定板、USB 工业线；
3. **第三批实测后补**：遮光、偏振、路由器、更高耐久 SSD 或 Orin NX；
4. **第四批需求明确后买**：DAQ、隔离触发和移动电源。
