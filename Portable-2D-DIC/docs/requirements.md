# 需求基线 v0.1

## 设备

- 相机：DAHENG ME2P-1840-21U3M，4504 x 4096，Mono8/Mono12，USB3；
- 第一阶段计算平台：Core Ultra 9 285H + RTX 5060 Laptop；
- 交付计算平台候选：Jetson Orin Nano Super 8GB + 1TB NVMe；
- 计算盒原型目标：不大于约 18 x 14 x 8 cm，重量不大于约 1.5 kg。

## 性能

- 全分辨率 Mono8 采集上限：21.4 fps；
- DIC 验收底线：不低于 10 fps；
- 正常目标：15 fps；
- 冲刺目标：接近 21.4 fps；
- 实时模式允许丢弃过期帧，不允许延迟持续累积。

## 软件

- DIC Edge：C++20/CUDA，负责相机、标定、DIC、应变、存储和网络；
- DIC Studio：Windows Qt/C++，中文界面，保留英文参数名和日志；
- Studio 默认浅色专业测量界面，支持深色；默认操作员模式，支持专家模式；
- Studio 采用项目中心和项目目录 + JSON 描述文件，六步工作流为项目、设备、图像与标定、
  采集、分析、报告；
- 中央图像/场图约 65%，右侧参数，底部曲线；目标 1920×1080、100%～150% 缩放；
- 界面明确区分张量剪切应变 `εₓᵧ` 与工程剪切应变 `γₓᵧ=2εₓᵧ`；
- 网络断开后 DIC Edge 必须继续执行当前实验；
- GalaxyView 用于开发和维护，GalaxySDK 用于正式相机控制；
- CPU 教学参考实现和 CUDA 工程实现并存。
